# AutoLib Android 原生客户端

这是 AutoLib 的原生 Android 客户端。界面由 Android View / Material Components 构成，直接调用后端 `/api/**` JSON 接口，不加载网页或 HTML。

## 已实现

- 原生主页：今日/明日预约、预约状态（含已结束/已违约/已到馆，到馆按图书馆座位状态判断，不再手动标记）、调整明日、本周配置预览、公告和预约结果
- 原生预约：选择区域、座位和时段后立即预约，支持常用座位快捷选择
- 按图选座：12 张楼层平面图上拖动缩放选座，点哪儿选中离它最近的座位，图上只标自己的优先级顺序；添加候选座位和立即预约都能进
- 原生预约操作：取消 / 离馆、一键午休续约；桌面小组件上的「取消预约」弹透明确认框后直接发请求，不进 App
- 座位热度：只在添加候选座位时点中某个座位才查它一个，底栏提示「AutoLib 中另有 N 人也选了」，平面图不按人数上色
- 原生配置：按星期/统一时段、一天多时段、候选座位优先级（拖拽排序，最多 3 个）、自动预约、迟到保护（含推迟后仍未到馆是「不再干预」还是「再探一次后取消」）和自动午休；密码不在配置页改，去「设置 → 账号 → 重新校验」
- 公告互动：每条公告后台配的表情按钮和应援按钮，表情飞向屏幕中间砸一下、应援从按钮上方冒出；连点攒 700ms 发一包，系统关了动画就只计数不飞
- 公告栏 Markdown：标题、粗体斜体、列表、引用、代码块、链接和裸链接，与网页端同一套语法
- 凭据验证：验证统一身份认证与图书馆 CAS 后保存
- 原生账号：添加学号即登录、资料编辑、退出以及多个图书馆学号切换
- 原生设置：主题（跟随系统/亮色/暗色）、邮箱通知（含「仅异常 / 全部」通知范围）、午休配置、学习记录、功能说明
- 图书馆信用分：设置页点「查询」才向图书馆查一次分数和扣分记录，没有任何定时任务会碰它
- 真实在馆时长：需用户同意开启，按图书馆的签到 / 暂离 / 返回记录统计实际在座时间；关闭时三选一（保留 / 模糊保留 / 删除），可导出 CSV 到系统「下载」
- 图书馆预约情况：设置页卡片看最近一天开抢 5 分钟后的全馆已约占比，点开是逐日折线（可点选某天）、那天从早到晚的曲线、探针的填充曲线和各区域占比，Canvas 自绘（`LineChartView`）
- 联系方式：由服务端 `/api/contacts` 按部署者配的 CONTACT_* 环境变量下发，APK 里不写死任何号码；一条都没配就不显示这张卡片
- App 内更新：下载带进度，下完直接拉起系统安装器，不跳浏览器；权限没给或下载失败都退回浏览器
- 升级检查：每次切回前台查一次（每天至多一次），不再只在冷启动时查
- Flask 会话 Cookie 本地持久化

## 登录模型

与网页端一致，**没有独立的登录/注册入口**。用户在「添加学号」里填写学号和统一
身份认证（网上办事大厅）密码，后端 `/api/my/accounts/<pid>/verify` 验证通过后
会把当前会话提升为该学号的登录态，配置随学号存在云端，换设备重新验证一次即可
找回。未添加学号前是只读的游客状态。

## 服务器地址

在 `app/build.gradle.kts` 的 `SERVER_URL` 中设置 HTTPS 后端地址：

```kotlin
buildConfigField("String", "SERVER_URL", "\"https://example.com\"")
```

后端必须部署本仓库 `backend/`，且客户端地址应能访问其 JSON API。

## 构建

项目需要 JDK 17 或更高版本、Android SDK 34 和 Gradle 8.x：

```powershell
cd android
.\gradlew.bat assembleDebug
```

调试 APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。发布包请配置自己的 signingConfig 后执行 `assembleRelease`，不要分发未签名的 release APK。

> 仓库若缺少 `gradle/wrapper/gradle-wrapper.jar`，可在安装了 Gradle 的环境中运行 `gradle wrapper --gradle-version 8.13` 补齐后再使用 `gradlew.bat`。
